# Project: Astraelyx Technologies — Modern Enterprise IT Services Website

Act as a senior UI/UX designer, enterprise website strategist, frontend developer, and brand designer.

Design and develop a complete, premium, production-quality website for **Astraelyx Technologies**, an IT services, cloud, AI, and digital engineering company.

## 1. Reference website and design objective

Reference website: https://www.helius-tech.com/

Analyze the reference website's publicly accessible pages and understand its:
- Enterprise positioning and messaging
- Homepage structure and navigation
- Service and industry sections
- Case studies and insights presentation
- Contact and conversion strategy
- Responsive layout and visual hierarchy

Use it as inspiration for information architecture and enterprise-quality presentation. Do NOT copy its source code, exact layouts, branding, text, images, or distinctive design. Create a unique visual identity for Astraelyx Technologies.

The final result should look like a credible, modern technology consulting and engineering company that can appeal to enterprise clients, CIOs, CTOs, IT directors, technology leaders, and growing businesses.

## 2. Brand identity and logo

Company name: Astraelyx Technologies

Use the existing company logo supplied in the project directory as `Logo.jpeg`.

First inspect the existing project files and locate the supplied logo. If necessary, create an `assets` folder and copy the logo there without changing the original.

Use the logo consistently in:
- Website header
- Footer
- Favicon, if an appropriate image conversion is possible
- Contact or brand section where appropriate

Do not recreate, distort, crop, or recolor the logo.

If the JPEG background is white, place it on a white or very light header so the logo looks natural. Preserve its aspect ratio.

Brand colors inspired by the logo:
- Primary navy blue: #0756B8
- Deep navy: #082B55
- Turquoise: #20CDB5
- Cyan accent: #36E2CB
- White: #FFFFFF
- Light background: #F5F8FC
- Primary text: #14243A
- Secondary text: #63738A

Use a restrained blue-to-turquoise gradient for selected highlights, buttons, decorative elements, and hero artwork.

Typography:
- Use Inter, Manrope, or a comparable modern sans-serif font.
- Use bold, confident headlines.
- Keep body text readable, with generous spacing and clear visual hierarchy.

## 3. Technical requirements

Build the website using ONLY:
- HTML5
- CSS3
- Vanilla JavaScript

Do not use React, Next.js, Vue, Angular, TypeScript, or a backend framework.

You may use Google Fonts, Lucide icons through a CDN, and carefully selected remote imagery if needed.

The website must:
- Run locally by opening `index.html` or using a simple local development server.
- Work on desktop, tablet, and mobile.
- Use semantic HTML and accessible controls.
- Have clean, reusable CSS classes and maintainable JavaScript.
- Include comments for important functionality.
- Avoid unnecessary dependencies.
- Avoid horizontal scrolling and layout overflow.
- Support reduced-motion preferences.
- Include SEO metadata, Open Graph metadata, and a proper page title.
- Use optimized images and lazy loading where appropriate.
- Avoid console errors and broken links.

## 5. Visual and interaction requirements

The design should feel like a premium enterprise technology brand, not a generic website template.

Include:
- Generous white space.
- Consistent content widths.
- Strong typographic hierarchy.
- Responsive grid layouts.
- Elegant cards with restrained shadows and borders.
- Rounded corners used consistently.
- Subtle blue/turquoise gradients.
- Smooth hover and focus states.
- Scroll-triggered reveal animations with IntersectionObserver.
- Smooth scrolling.
- Mobile navigation open/close functionality.
- Functional dropdown navigation where used.
- Back-to-top control if it improves usability.
- Accessible form validation.
- Clear hover and keyboard focus states.

Use motion sparingly. Avoid excessive parallax, distracting particles, huge animated gradients, or slow-loading effects.

## 6. Responsive design

Implement mobile-first CSS with breakpoints for:
- Small mobile: 320–480px
- Tablet: 481–768px
- Laptop: 769–1200px
- Desktop: 1201px and above

On mobile:
- Use a compact logo and hamburger navigation.
- Stack hero content vertically.
- Keep buttons large enough to tap.
- Convert service and industry grids to one column or two columns where space permits.
- Ensure no horizontal overflow.
- Reduce or disable decorative animations where appropriate.

## 7. SEO and accessibility

Add:
- Unique page title and meta description.
- Canonical URL placeholder, not a fabricated domain.
- Open Graph title, description and image placeholder.
- Semantic header, nav, main, section and footer elements.
- Logical heading hierarchy.
- Descriptive image alt text.
- Accessible form labels.
- ARIA attributes for interactive navigation where appropriate.
- Visible keyboard focus indicators.
- Reduced-motion support.
- Descriptive internal links.

Do not include fabricated structured data for reviews, ratings, addresses or business claims. If appropriate, add a basic Organization JSON-LD block only after the correct company details and website domain are supplied.

## 9. Development workflow

Follow this sequence:

1. Inspect the current working directory and identify the supplied logo.
2. Inspect the reference website to understand its high-level design and information architecture.
3. Plan the page structure and reusable CSS design system.
4. Create the HTML, CSS and JavaScript files.
5. Implement the responsive design and interactions.
6. Verify that image paths, navigation links and assets work.
7. Run the site using the available local development server if possible.
8. Inspect the site at desktop and mobile widths.
9. Fix layout issues, missing assets, console errors and accessibility problems.
10. Update README.md with setup instructions and any configuration requirements.

If browser preview or screenshot tools are available, use them to inspect the rendered page and refine the design.
